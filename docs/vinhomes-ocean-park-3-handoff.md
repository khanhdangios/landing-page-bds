## 7. Component Design System

### Color Tokens

- `color-primary`: #0F172A
- `color-secondary`: #D4AF37
- `color-background`: #FFFFFF
- `color-cta`: #C9A227
- `color-text`: #111827
- `color-muted`: #64748B
- `color-surface`: #F8FAFC
- `color-border`: #E5E7EB

### Typography

- Heading font: Playfair Display
- Body font: Inter
- H1 desktop: 64-80px, line-height 1.05
- H1 mobile: 36-44px, line-height 1.12
- H2 desktop: 44-56px, line-height 1.12
- H2 mobile: 28-34px, line-height 1.18
- Body: 16-18px, line-height 1.6
- Button: 15-16px, font-weight 700

### Components

**Button Primary**
- Background #C9A227
- Text #0F172A or #FFFFFF depending contrast
- Border radius 999px
- Height 52-56px desktop, 48-52px mobile

**Button Secondary**
- Transparent / navy border
- Hover: light gold surface

**Lead Form Card**
- Surface white
- Shadow soft
- Border 1px #E5E7EB
- Radius 16px
- Form fields height 48-52px

**Info Card**
- Icon top
- Title
- Description
- Optional CTA text link

**Gallery Card**
- Aspect ratio 4:3 or 16:10
- Rounded 16px
- Image overlay gradient for caption

**Sticky CTA Bar Mobile**
- Fixed bottom
- Two equal buttons
- Safe-area padding for iOS

## 8. Animation Suggestions

- Hero text fade-up 700ms, delay stagger 100ms.
- CTA subtle gold glow on hover.
- Stats count-up when visible.
- Cards reveal on scroll with 16px translateY.
- Gallery hover zoom 1.04x.
- Form card sticky only on desktop within hero or final section.
- Avoid heavy parallax on mobile.

## 9. CRO Checklist

- Hero has one clear value proposition above the fold.
- Primary CTA appears in first viewport.
- Form is visible early and repeated at bottom.
- CTA copy is specific: "Nhan bang gia moi nhat" beats "Dang ky".
- Phone field is required; other fields optional or progressive.
- Trust proof near form: chu dau tu, vi tri, loai hinh, tu van nhanh.
- FAQ answers objections before final form.
- Sticky CTA on mobile.
- Use real project visuals, avoid generic stock city images.
- Add privacy reassurance near form.
- Track events: CTA click, form submit, phone click, scroll depth 50/75/90, FAQ expand, gallery click.
- A/B test hero CTA: "Nhan bang gia moi nhat" vs "Nhan mat bang va quy hang".
- A/B test form length: 3 fields vs 5 fields.
- A/B test hero visual: ocean amenity vs villa/shophouse product.

## 10. Development Notes

**Recommended stack:** Static HTML/CSS/JS or React/Next.js if lead tracking, SEO routes and CMS are required.

**Performance:**
- Compress hero image and gallery images.
- Use responsive images with `srcset`.
- Lazy-load gallery images.
- Preload hero image and fonts.

**Analytics:**
- Google Tag Manager
- Meta Pixel
- Conversion API if running paid ads
- Form submit webhook to CRM/Google Sheet

**Accessibility:**
- All CTA buttons need accessible names.
- Form inputs need labels.
- Color contrast for gold text on white must be checked; avoid small gold text on white.
- Keyboard accessible FAQ accordions.
